# Luno — Mis primeros 25 soles

Animación 2D original: 120 segundos, 1080 × 1920, 30 FPS.

## Descargar

- [Video completo, 1080p](Luno-video-1080p.mp4?raw=true)
- [Video ligero, 540p](Luno-video-ligero.mp4?raw=true)
- [Proyecto editable Motion Canvas / TypeScript](Luno-proyecto.zip?raw=true)
- [Subtítulos en español](Luno-subtitulos.srt?raw=true)

Los videos incluyen música, efectos y subtítulos, sin voz hablada. El ZIP contiene las doce escenas, el personaje articulado, las pistas de audio separadas, una pista guía de narración y las instrucciones para ejecutarlo en Windows.

Si GitHub muestra la página del archivo, usa **Download raw file** o el botón de descarga. Para el proyecto, descarga el ZIP anterior: no necesitas descargar todo este repositorio.
